# GermiCount 🌱

**GermiCount** is an AI project designed to analyze seed viability by identifying, classifying, and counting **germinated** and **non-germinated** seeds from images.

---

## 📌 Project Overview

Evaluating seed germination is essential in agriculture and plant science to measure seed quality and growth potential. This project aims to automate seed counting and germination rate analysis using computer vision and machine learning.

### Objectives
- **Seed Classification**: Distinguish between germinated and non-germinated seeds.
- **Germination Rate Calculation**: Automatically calculate the germination percentage (`(Germinated / Total) * 100%`).
- **Automated Seed Counting**: Replace manual counting with machine learning analysis.

---

## 📊 Dataset

This project uses the [Germinated and Non-Germinated Seed Dataset](https://www.kaggle.com/datasets/shajinrp/germinated-and-non-germinated-seed/data) from Kaggle.

* **Classes**:
  - `Germinated`: Seeds showing root emergence or sprouting.
  - `Non-Germinated`: Unsprouted or dormant seeds.
* **Dataset Source**: [Kaggle - shajinrp/germinated-and-non-germinated-seed](https://www.kaggle.com/datasets/shajinrp/germinated-and-non-germinated-seed/data)
